**Web Development & Deployment Bootcamp**

I had the opportunity to attend an engaging Web Development & Deployment Bootcamp conducted by Being Infinity at JNTUH. The workshop was structured across two intensive days with hands-on learning:

**Day 1: Foundations & Version Control**
Git & GitHub – Learned version control fundamentals, repository management, and collaborative workflows

Web Fundamentals – Understood how web pages work behind the scenes (UI rendering, browser behavior)

HTML & CSS – Built a toggle user page from scratch with detailed explanations of every concept

Interactive Kahoot quizzes and leaderboard challenges with prizes

**Day 2: APIs & Dynamic Web Applications**
Responsive Design – Created a responsive page that displays random user data

API Deep Dive – Hands-on practice with RESTful APIs:

GET – Fetching data from external sources

POST – Sending data to servers

PUT – Updating existing resources

DELETE – Removing data from servers

Interactive Kahoot quizzes and leaderboard challenges with prizes

**Key Takeaways**
This workshop gave me practical exposure to the complete web development lifecycle—from version control and frontend design to API integration and deployment. The interactive learning environment with quizzes and prizes made the experience both educational and enjoyable.
